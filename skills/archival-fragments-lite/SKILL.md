# Archival Fragments(简版)
这个 skill 只固定两件事:**这套视觉风格**,和**参考图 → 首尾帧**的做法。
不绑定模型、不装依赖、不代跑流程。你用什么图片模型、什么视频工具都行,只要那个视频工具**支持首尾帧**。

## 视觉风格
- 满幅象牙纸底色
- 单色印刷(黑白)
- 单一暗砖红作为强调色
- 纸质拼贴/档案剪贴的编辑设计感

## 三条硬约束
违反任何一条,出来的片子必废。

### 1. 每一镜的参考图必须不同
N 个镜头需要 **N+1 张各不相同的参考图**。第 1 镜的尾帧 = 第 2 镜的首帧,这一张图被这两镜共用。
**绝对禁止**:拿同一张图当所有镜头的输入;拿结构图/示意图当所有镜头的参考。
**自检**:参考图张数 == 镜头数 + 1;任意两张的画面描述不重复。

### 2. 具象优先,不要抽象图形
纸和红线是画面的**地面**,不是主体。站在上面的必须是观众不用想就懂的具体东西:
| 语义 | 符号 |
|---|---|
| 谁在哪、份额、从无到有 | 世界地图 + 图钉 + 标签 |
| 价格、代价、失衡 | 天平(一端实物,一端不断加码) |
| 排名、递进、还差多远 | 台阶 / 领奖台 |
| 数量、密集、庞大 | 一大堆实物 |
| 时间点、正式性 | 翻牌板、印章、公文 |
| 被否定、被抹掉 | 一只手把东西撕走 / 白纸盖上 |

### 3. 慢不等于静
每一镜结尾画面必须和开头**明显不同**。留白镜也要有一个横跨画面的动作在推进。首尾帧天然帮你守住这条。

## 三步做法
### 第一步:拆镜,列出参考图链
把文案按句拆成镜头(每句 2-3 镜),设计一条连续的视觉旅程:
```
A01 ──W01──> A02 ──W02──> A03 ──W03──> A04 ...
```
画面推进只有四种合法方式:物件变化、景别变化、状态变化、主体更替。
**拆完先给用户过目**——改一张表 5 分钟,重新生成要几小时。

### 第二步:出参考图
**文生图**,一张一个提示词,不挂任何参考图。每张提示词 = 固定风格前缀 + 该张画面。
出完**逐张审**:文字有没有崩、语义观众看不看得懂、能不能和前后接上。图便宜、视频贵,这一步省不得。

### 第三步:用首尾帧生成镜头
每镜挂两张图:第 N 张作首帧、第 N+1 张作尾帧。提示词**只写运动**,一句话。
生成时长:多数工具最短 5 秒,而这个风格每镜通常只用 1-3 秒。**统一生成 5 秒,剪辑时变速压到目标时长**。

## 对工具的要求
| 环节 | 要求 |
|---|---|
| 图片 | 能出你要的比例(推荐 4:3),文字渲染较准 |
| 视频 | **必须支持首尾帧**——也叫「首尾帧」「first & last frame」 |

## 与 wayne-video 主管线的衔接
主管线 `gen_segments.py` 支持即梦/H3 等多后端的首尾帧生成;本 skill 提供「参考图链 → 首尾帧」的方法论和档案剪贴风格。两者结合:用主管线的生成引擎执行本 skill 的首尾帧方法,产出风格化短片。主管线的 `assemble.py` 负责最终拼接和变速。
