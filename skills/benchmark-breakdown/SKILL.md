# 对标账号拆解 Skill
做一件事:**给一个链接,把对方的内容拆到能复用的程度。**
产出固定三件套:
1. **可复用爆款公式** —— 提炼成能直接套用的选题套路 + 结构模板 + 视觉公式。
2. **画面 + 口播逐段拆解** —— 时间轴对齐,逐段标注画面/口播/钩子/节奏/转折/CTA + 两者协同方式。
3. **人设与内容定位** —— 人设标签、视觉符号、内容矩阵、差异化打法。
> 这是**分析型** skill,产出 markdown 报告,不产图。拆解结果可直接喂给 wayne-video 主管线的反推引擎(seed_reverse.py)做结构化复刻。

## 工作流
0. **前置清单**:Docker、Douyin_TikTok_Download_API、XHS-Downloader API、ffmpeg、openai-whisper。缺什么先补环境。
1. **识别**:从 URL 判断平台 + 粒度(单条/账号)。
2. **准备证据包**:自动下载视频/图片、转写 audio.txt、抽帧并生成 contact sheet。
3. **取数回退**:① 平台本地 API(主力) → ② TikHub(备用) → ③ Jina Reader → ④ 引导粘贴。
4. **短视频必做**:下载 + 转写口播 + 抽视觉帧(三样都缺不可)。抽完帧用多模态读图。
5. **拆解**:按通用四层 + 视觉七维 + 平台特化分析。画面与口播必须时间轴对齐。
6. **输出 + 存档**:生成三件套报告,存到 benchmarks/<平台>-<账号名>/<日期>-<标题slug>.md。
7. **收尾**:给「这条/这个账号最值得我抄的 3 个点」+ 一句可执行的下一步建议。

## 铁律
- **自检通过就自动开干**:完成下载 → 转写 → 视觉识别 → 爆款拆解 → 存档。
- **永不空手而归**:逐级回退走完;真抓不到就引导粘贴。
- **短视频必转写 + 必读图**:口播 + 画面 contact sheet 两个证据都要。
- **报告末尾必须附完整转写稿**:不能只写摘要。
- **要可复用,不要复述**:提炼为什么这么做、我怎么套用。
- **始终存档**到 benchmarks/。

## 与 wayne-video 主管线的衔接
拆解产出的爆款公式和逐段拆解,可作为主管线 `seed_reverse.py` 反推的创意输入;拆解存档的 benchmarks/ 是长期对标库,为主管线的 B 模式(跨类目迁移)提供选题和结构参考。
