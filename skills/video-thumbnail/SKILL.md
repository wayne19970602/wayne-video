# 视频封面生成
做一件事:**给视频做高点击率的封面(缩略图)**。主战场 B站、YouTube、抖音/视频号。

核心技法是 **pop-out**:
```
底层:人物的原始照片,压暗 + 降饱和(保留房间/桌面等环境 → 真实感)
中层:大标题(关键词=黄色实色块),压在暗化原图上
顶层:把人物从原图里抠出来,全亮、原位精确叠回去
      → 人物"从自己的场景里跳出来"
```
一套内容用 CSS 重排成 **16:9 / 4:3 / 3:4**(重排,不是裁切)。

## 一次性 setup
```bash
pip install "rembg[cpu]" onnxruntime
python3 -m playwright install chromium
```

## 工作流
1. **读输入**:用户口语需求 + 一张真人照片(有环境感更好)。
2. **想清楚**:标题砍到 8-16 字、断 2-3 行、哪个词做黄色块;人物在左还是右。
3. **抠图**:`python3 src/cutout.py <照片> input/person-cut.png`。输出整幅(不裁外框)。
4. **写 brief.json**:photo=原图, person_image=抠图(两者必须是同一张)。
5. **渲染**:`python3 src/render.py <brief.json> output/` → 3 张高清 PNG。
6. **视觉自检**:关键词被人物挡到读不出、背景压太暗/太亮,就调 focus 或字号重渲。
7. 交付 + 简述取舍。

## 三套模板
| 模板 | 风格 | 适合 |
|---|---|---|
| `popout`(默认) | 深色海报风,大白字+黄色关键词,人物全亮跳出 | 大多数视频,强冲击 |
| `ui` | 深色命令面板风,标题做成"在 AI 工具里输入的查询" | 工具/AI/自动化类 |
| `paper` | 浅色胶片编辑风,褪色照片+胶片颗粒+iOS选中高亮 | 观点/故事/高级感选题 |

## 品牌铁律
- pop-out 三层不能破:暗化原图(留环境) → 文字 → 全亮抠图人物(原位对齐)。
- 人物全亮跳出、第一主体;标题第二,关键词用黄色实色块。
- 人物可盖住部分文字,但关键词必须仍可读。
- 背景压暗适度,别压死——环境要看得见才有真实感。
- 三比例各自重排,不是裁切。

## brief.json 字段
| 字段 | 说明 |
|---|---|
| template | popout(默认)/ ui / paper |
| title | 标题;\n 换行,[方括号]包关键词=黄色实色块 |
| photo | 原图路径(底层背景) |
| person_image | 抠图路径(顶层人物,须与 photo 同源) |
| person_side | right(默认)/ left |
| ratios | 默认 ["16x9","4x3","3x4"] |

## 与 wayne-video 主管线的衔接
主管线 `deliver.py` 输出剪映草稿和成品视频;本 skill 在视频制作完毕后生成高点击率封面。封面用的人物照片可来自主管线 `make_host.py` 生成的主播锚图,实现"同一人设贯穿视频和封面"。
