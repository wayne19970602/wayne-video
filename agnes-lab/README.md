# Agnes AI 独立替代调研

核对日期：2026-09-07。范围：当前项目的模型调用环节；本目录独立存放调研，不接入主流程。结论依据官方模型专页与本地 README.md、DESIGN.md、config.py 及反推、说话人标注、评委调用代码。尚未调用 Agnes 推理 API，也没有生成质量、速度、账单实测。

## 结论

优先试图片资产生成、文本改写和无口播图生视频。原生视频反推、逐字转写、说话人归属、指定音频逐字对口型仍有关键缺口。不能因为概述写了“多模态”或“OpenAI 兼容”就整体换掉旧链路。

下表“候选”是基于接口能力的工程判断，不代表效果已经超过现用模型。官方关于新模型更强的描述仍需要同素材对照。

## 各模型对应环节

| 模型 ID | 项目中的候选替代环节 | 边界与建议 |
|---|---|---|
| agnes-2.0-flash | 不新增接入 | 已废弃，官方建议转 2.5 Flash |
| agnes-2.5-flash | 本地化文案初稿、资产描述、已抽帧图片的视觉问答 | 首轮文本候选；不承担确定性路由、重试、JSON 转换；不能确认支持原视频及音轨输入 |
| agnes-2.5-pro-alpha | 不新增托管 API 接入 | 托管 API 已废弃；开源权重仍可用，但自部署不属于这次试验 |
| agnes-2.5-pro-beta | 复杂脚本重写、反推分歧的图文辅助裁决、图文质量评审 | 可作付费对照；输入明确为文字和图片，不能等同带音轨视频评委 |
| agnes-2.5-pro | 同上，更适合作为稳定版候选 | 需要对照动作、颜色、角色、产品事实的保留率；当前单价高于 Beta |
| agnes-image-2.0-flash | make_host / make_cast_sheet / make_scene 的图像生成部分 | 支持文生图、图生图、多图组合；可作旧版基线 |
| agnes-image-2.1-flash | 同上，复杂场景板、人设板 | 官方称强化复杂构图与细节；不能替代真实产品照片 |
| agnes-image-2.5-flash | 同上；封面和分镜参考图也可试 | 优先图片候选，和 2.1 共用参数契约；用 3:4 人设图、真实产品图检验一致性与文字保真 |
| agnes-video-v2.0 | gen_segments 的纯产品/氛围 i2v 分支 | 支持文生视频、图生视频、多关键帧；没有明确的指定音频口型契约。帧数须满足 8n+1 且不大于 441；尺寸可能被归一化 |
| agnes-video-2.5-flash | 无口播镜头优先；多图+音频参考作为单独实验 | 仅 720P，4–12 秒，最多 5 图、3 音频，不支持视频参考。不能直接视为 H3 音频驱动口型替代品 |
| agnes-video-2.5 | 高分辨率图生视频、多模态参考、短参考视频动作迁移 | 4–12 秒；支持 720P/1080P/1K/2K。可测原片短段参考+新产品图，但生成参考不等于输出结构化反推结果 |

## 现有流程仍需保留的内容

1. **视频反推与台词证据**：seed_reverse、k3_reverse、speaker_tag、verify_dialogue 的原视频/音轨能力暂未找到等价 Agnes 契约。可另建“硬切抽帧+ASR+图文模型”路线，但稀疏图片会遗漏瞬时动作，必须单独验收。
2. **精确声音链路**：CosyVoice TTS、cut_audio 原音切段、Seed-VC 换声、句级 timing.json。视频自带声音不等于可以交付独立 WAV、准确字幕轴或复现指定表演。
3. **确定性工程**：route、plan 的切点与动作完备性检查、director、合并裁决的数据整理、异步任务状态、下载解码校验、assemble、字幕及剪映草稿。仍由代码负责。
4. **真实素材与人审**：用户产品图、包装原文、新人物身份确认、说话人确认。生成模型不能成为产品事实来源。
5. **验收**：原片与成片的同时间点对照、人数与手部检查、旁白镜张嘴检查、跨镜人物与音色一致性。Agnes 图文模型仅能先试辅助帧评审，不能宣布替代 judge 的双视频评审。

## 还需要补哪些内容

### 向平台确认的接口能力

- 文本模型是否接受原生视频和音轨；若接受，需要准确 content 类型、文件上传方法、时长/文件大小上限、时间戳与多视频输入示例。目前专页明确列出的仅是文字和图片。
- 音频 reference 能否逐字复现台词、保留原声、绑定指定人物并实现口型同步；是否存在纯节奏/风格参考与精确驱动两种模式。需要可复现例子及支持边界。
- 是否另有 ASR、词级时间戳、说话人分离、独立 TTS、声音转换接口。本次完整模型索引中未找到这些专页。
- JSON Schema / structured output 是否严格支持；多图理解数量与分辨率限制；不能只靠提示词要求 JSON。
- 各账户并发、排队时长、限额、免费活动到期、失败计费、任务保留时长、结果 URL 有效期，以及提交超时后如何查回原任务避免重复扣费。
- 包装文字、人物身份和音频效果需要实测，不能靠营销描述补齐。

### 独立试验需要补的实现

- 三类适配器：文本/图像/视频；读写本目录中的输入副本与结果，不导入主项目带凭证初始化的模块。后续凭证统一接本机 api-manager，不写入源码。
- 素材 URL 层：视频参考要求服务端能访问的 URL，本地 D 盘路径不能直接传；需确定存储位置与链接有效期。图片生成接口则明确支持 URL 或 Data URI。
- 请求转换：图片生成用 image 数组、size 和 ratio；视频 2.5 用 images/audios/videos、字符串 seconds、aspect_ratio。主项目的 @图片、H3 的说话人标记需要重写适配。
- 持久化 task_id、video_id、模型名、请求快照、状态与成本；轮询失败不直接重新生成；下载后用 ffprobe 核对时长、尺寸、音轨。
- 保持原输出契约：shotlist.json、segments.json、audio/seg/*.wav、timing.json、clips/*.mp4。只在验证通过后讨论主流程接入。

### 首轮测试素材与判定

需要一个真实 SKU 的产品/包装照片和一段有代表性的原视频，并明确可使用的素材范围；另准备校对台词、主体动作、关键颜色与角色归属真值。

| 顺序 | 单样本测试 | 必须记录的结果 |
|---|---|---|
| 1 | Image 2.5 生一张人设板和一张场景板 | 3:4 人设规格、人物身份是否一致、场景板是否混入人物 |
| 2 | Video 2.5 Flash 真产品首帧、无口播 | 包装字/产品形态、动作是否实现、实际尺寸时长、排队时间 |
| 3 | 同一段台词+一张人物图，测试音频参考 | 逐字正确率、音色、口型、说话人归属；失败则继续保留现有口播后端 |
| 4 | 需要动作参考时才测标准 Video 2.5 | 参考动作保留、新产品替换、是否带入原角色、真实账单 |
| 5 | Flash/Pro 处理同一份已核对图文证据 | 动作和关键颜色是否丢失、JSON 合法率、产品事实是否被编造 |

先过单样本再批量。生成成功只证明接口可调用，不等于可以接管业务环节。

## 接口容易踩坑的地方

- 视频创建：POST https://apihub.agnes-ai.com/v1/videos。
- 2.5 系列推荐查询：GET https://apihub.agnes-ai.com/agnesapi?video_id=...&model_name=...。查询路径不在 /v1 下，且所有模式都带模型名。
- 标准 2.5 和 Flash 的 keyframe 模式不能混用 images/audios/videos；reference 模式不能放 first_frame/last_frame。首帧强控和音频参考不能在同一请求中随意拼接。
- reference 允许重新构图与调整节奏，不能当成逐帧复刻保证。Flash 的短时长下限为 4 秒，项目中 1–3 秒镜头需要统计裁切浪费。
- Video V2.0 是另一套 image/num_frames/frame_rate 参数，不共用 2.5 的时长转换。

## 成本（查询日官方国际站美元价格）

Flash 文本、三代图片、Video V2.0 及 Video 2.5 Flash 当前显示免费；活动、账户限制和期限仍需核对，不能按永久免费做商业测算。

Pro 输入/输出分别 $0.45/$0.90 每百万 token；Beta 分别 $0.10/$0.30。标准 Video 2.5 的 720P 为 $0.025/秒，1080P 与 1K 为 $0.040/秒，2K 为 $0.055/秒；输入视频时长也计费，第 6 张起参考图每张 $0.005。例如 8 秒输出+3 秒参考视频+7 图，720P 刊例费用为 (8+3)×0.025+2×0.005=$0.285，不含重试与其他服务。
